# CZP v2

The **Comprehensive Zombies Project** — now completely reconstructed using **Vite, React, Tailwind CSS, and TypeScript**.

CZP is a side project dedicated to compiling information about Call of Duty Zombies maps from a wide variety of sources into one comprehensive resource.

The goal is to preserve as much information as possible in one place, helping prevent useful information from being forgotten and reducing the spread of inaccurate or outdated information.

All sources are credited for each map in the **Credits** tab, with relevant videos attached to the sections they support. (If you see your source linked and want it removed, request it.)

There will likely be some typos throughout the project, as much of the information is written quickly without extensive proofreading. However, the information itself is intended to be accurate and is either taken directly from reliable sources or modified when more accurate information has been found.

## How to Help

If you would like to contribute to the project:

- Copy the **most recent version of the template** from Template.tsx.disabled folder and use it for any map that either has an outdated version or does not have information yet. (PLEASE ENSURE THE MAP FILE HAS NO INFORMATION BEFORE CHANGING TEMPLATES)
- Update the template's information to accurately reflect the map. This only includes renaming the 2 functions at the very end of the template.
- **Please cite every source used accurately** in the **Credits** tab. Look at existing completed pages to follow the established formatting.
- All information should either be **written by hand or copied from a source and then tested**. If something cannot be tested directly, compare it against multiple reliable sources to verify that it is accurate.
- **Please do not blindly trust AI-generated information**, especially for Easter Egg steps or other detailed instructions. Always verify the information yourself.
- If you believe a map marked as **completed** is missing information or contains an error, feel free to add or correct it. Just remember to properly credit any sources used.

## Useful Research Sources

These are some of the sources that can be useful when researching maps:

- **[COD Zombies Guides](https://www.codzombieguides.com)** — Some maps contain a large amount of information, although others may be incomplete or primarily covered through videos.
- **[Reddit CODZombies Wiki](https://www.reddit.com/r/CODZombies/wiki/index)** — Very comprehensive information and guides for certain maps.
- **[Fast Guides Glitch](https://www.youtube.com/@FastGuidesGlitch/featured)** — Fast, concise Easter Egg and side Easter Egg guides, particularly for BO4 and newer games.
